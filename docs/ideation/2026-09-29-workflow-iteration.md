# 2026-09-29 操作流程与终端体验迭代

## 代码分析

当前产品是 Python/Rich 终端漫画下载器。源注册、SourceProfile、浏览器生命周期、
页面加载、图片下载、打包和展示已拆分，具备多源搜索、范围下载、已有文件复用、
自动重试和逐话下载汇总。本次检查以本地代码和离线测试为依据，不将历史站点状态
视为当前线上可用性的证明。

影响日常操作的主要缺口集中在命令边界：

| 维度 | 检查发现 | 本轮实现 |
| --- | --- | --- |
| UI/UE | 缺少会话状态入口，下一步操作依赖记忆 | `status`、统一 `help`、搜索/详情后的下一步提示 |
| UI/UE | 固定三列章节在窄终端拥挤；外部标题可能被当成 Rich 标记 | 随终端宽度展示 1～3 组章节列；窄屏搜索精简；外部字段按字面显示 |
| 可操作性 | cmd.Cmd 空行重放上一命令；未处理 EOF | 空行无操作，EOF 正常清理退出 |
| 可操作性 | 源选择仅支持循环数字输入，缺少取消 | 支持源名/序号直接选择、菜单取消、空源提示和能力说明 |
| 状态一致性 | 切换源、详情请求失败可能留下旧漫画 | 清除旧详情，保留可继续选择的搜索结果 |
| 功能完整性 | 不支持的 URL、无效范围、部分失败也可能返回 0 | 命令执行状态传递至 CLI；参数错误 2，执行失败 1，中断 130 |
| 错误恢复 | 详情解析异常可能退出交互进程 | 命令边界记录日志、显示错误并允许继续操作 |
| 源匹配 | URL 使用字符串前缀判断 | 解析主机和端口，拒绝相似域名及含凭据的 URL |
| 资源管理 | 搜索会话未关闭；Context 重复创建 HTTP 会话 | 独立搜索会话随任务结束关闭；退出时关闭主会话 |

`do_*` 命令的返回值仍遵守 cmd.Cmd 的退出约定，执行成败单独记录，避免成功下载后
意外退出交互会话。直接子命令没有搜索会话，因此帮助与校验均要求 URL。

- CLI 测试覆盖参数预检、三种范围形式、错误退出码、下载成功/跳过/部分失败/失败。

## 后续开发方向（独立迭代）

1. **下载任务恢复**：保存 URL、分组、范围和结果清单，支持重启后列出与重试失败任务。
   当前重新运行同一命令可以复用本地文件，但没有持久化任务队列。
2. **源诊断与搜索进度**：把源内部的页面加载失败与正常空结果明确区分；逐源完成时即时
   更新搜索进度。当前源适配器可能将失败转为空列表，不能仅凭空结果断言站点可用。
3. **长列表浏览**：对大体量搜索和章节列表增加分页、过滤或指定分组展示，保留稳定序号。
4. **下载文件完整性**：完善现有图片/ZIP 的有效性校验，避免仅凭存在与大小复用损坏文件。
5. **工程质量**：按源逐步修复历史静态检查问题，配合脱敏网页样本做解析回归。

本轮保留现有 CLI 产品定位，并完成上述操作流程的闭环。后续方向各自需要明确的数据
格式、兼容策略及验收样例，适合独立提交与验证。
