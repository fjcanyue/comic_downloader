# 2026-10-13 任务浏览与轻量摘要缓存

## 代码分析与本轮实现

基线为 `cb9f239`，全量测试 322 项通过。搜索与漫画章节已有分页，但 `tasks`
仍一次性反序列化全部任务并输出完整表格，任务详情也展示所有章节。历史记录增加时，
这些行为使定位失败项困难，并反复分配大量章节/图片对象。

本轮沿用 cmd.Cmd 与 Rich，任务 JSON 格式和下载/恢复流程保持兼容，不新增依赖。

| 问题 | 实现 |
| --- | --- |
| 任务/章节列表过长 | 列表每页 20 项，详情每页 30 话；交互与直接子命令均使用明确分页 |
| 失败项被成功记录淹没 | `all / unfinished / failed / completed / pending` 筛选；任务列表另支持 `running / interrupted` |
| 翻页要重复输入 ID 与条件 | `tasks next/prev` 沿用当前视图，`tasks` 返回全部任务第一页 |
| 短 ID 冲突或筛选后难以定位 | 从全部有效任务计算唯一短 ID；进入详情后记住完整 ID；章节展示计划原序号 |
| 重复解析历史 JSON | 每条任务仅缓存不可变摘要和文件签名，记录未变化时直接复用 |
| 外部进程可能更新记录 | 每次扫描文件名及纳秒时间戳、大小、文件标识；读取前后签名不一致时不缓存本次快照 |
| 窄屏详情挤压 | 40 列下合并分组/章节、状态/说明，外部文本按字面渲染 |
| CLI 参数错误发现过晚 | 共享任务命令解析，非法状态/页码及无会话的 next/prev 在创建 Shell 前返回退出码 2 |

任务状态筛选与章节状态筛选有明确区别：任务 `failed` 匹配持久化状态，章节 `failed`
包含完全失败及部分失败；`unfinished` 按尚未完成的章节计算。`running` 不代表进程必然在线。
筛选不改变下载或重试范围，重试仍处理计划的全部未完成章节。详情的原序号是计划中的
跨分组位置，不是 `v` 的分组内话序号。

缓存不写额外索引，首次扫描仍完整校验每个 JSON，只在一个记录解析期间保留其完整对象；
后续只保留 O(任务数) 的轻量摘要，不保留全历史的章节/图片列表。损坏或无法读取的记录
不使用旧缓存冒充成功，独立报告错误；删除记录会清理对应缓存。
并发更新期间可能看到一次读取时的快照，后续浏览会重新检查；不承诺跨多个文件的事务快照。
详情与重试仍读取原记录。任务归档、删除与后台队列不在本轮改动范围内。

## 性能测量

在本机临时目录创建 200 个任务，每个任务 100 章，包含成功、失败和未处理记录。
使用 `tracemalloc` 测量读取阶段的 Python 峰值分配，另用 `perf_counter` 记录耗时：

| 读取方式 | 峰值分配 | 单次耗时 |
| --- | ---: | ---: |
| 原有完整任务列表 `list_jobs` | 13.34 MiB | 0.607 秒 |
| 首次轻量摘要 `list_summaries` | 0.54 MiB | 0.569 秒 |
| 同进程、记录不变时再次读取摘要 | 0.23 MiB | 0.015 秒 |

这些数字仅是该合成数据集的本机离线观察，受磁盘、文件系统缓存与记录规模影响，
不是网络下载提速或所有运行环境的承诺。回归测试另外验证未变化记录不重复解码，
外部更新仅重读变化记录，避免依赖不稳定的耗时阈值。

## 验证范围

- 命令解析、纯数字 ID 前缀、状态语义、分页边界与稳定排序。
- 计划列表到详情、失败筛选后翻页、全 ID 状态保持、无匹配与损坏记录提示。
- 筛选不改变当前漫画，也不改变 `retry` 恢复全部未完成章节的行为。
- 摘要缓存复用、其他实例更新、新增/删除、损坏/修复、相同大小/时间的原子替换、读取过程中的替换。
- 40/80/120 列任务输出、字面错误信息、原章节编号及直接子命令导航提示。
- 全量 pytest、本轮文件 Ruff 检查与格式检查、包含 `main.py` 的 Pyright 检查、`git diff --check`。

README 的任务演示图由 Rich 实际渲染生成，明确标注演示数据，不表示线上下载结果。

最终结果：**363 项测试通过**，较基线新增 41 项；9 个修改/新增 Python 文件的 Ruff
检查和格式检查通过；`main.py`、`downloader`、`tests` 的 Pyright 检查零错误、零警告。
独立进程通过任务列表首页/次页、详情次页、空筛选、非法参数、页码越界、交互连续翻页
七组冒烟检查；退出码分别符合 0/2/1 的语义，浏览前后任务文件逐字节一致，未产生索引或锁文件。
