# 搜索结果键盘浏览与同屏详情：设计和可行性评估

状态：设计方案；界面机制验证通过，尚未接入应用。评估基线：`f0a0f62`。

## 目标与结论

搜索漫画后，可以用上下方向键移动高亮，按 `Enter` 在同一个终端画面的另一区域加载高亮漫画的
详情；按 `d` 弹出整本下载确认框，确认后执行与 `d <漫画原序号>` 相同的下载流程。宽终端左右
分栏，较窄终端上下分栏。用户不需要记住序号并反复输入命令。

结论：**技术上可行，建议使用已有 prompt_toolkit 增加独立搜索浏览模式**。这是输入、状态和
异步加载方式的调整，不能只给现有 Rich 表格增加高亮颜色。应用开发应分步实施，真实浏览器
加载和退出清理验证通过后，才把自动进入浏览模式作为默认行为。

本次只做代码分析、交互设计和隔离原型验证，没有改变应用命令、下载行为或现有运行入口。

## 代码依据

| 位置 | 当前行为 | 对设计的影响 |
| --- | --- | --- |
| `downloader/shell.py:Shell` | 继承 `cmd.Cmd`，`use_rawinput=False`，按行读取命令 | 不能直接使用当前输入循环接收方向键及不需回车的 `d` |
| `Shell.do_s` | 完成搜索后合并完整结果，输出 Rich 表格 | 可以在搜索结束后用现有结果快照进入浏览器，无需重新搜索 |
| `search_result_indices` | 筛选结果保存原始列表索引 | 浏览器可以维持原序号，避免筛选后下载到另一条结果 |
| `Shell.do_i` | 清空当前漫画、切换源、同步加载详情、直接输出 | 不能从界面后台线程直接调用，需要拆出返回数据的详情加载边界 |
| `Shell.do_d` | `d` / `d <序号/URL>` 表示下载 | 浏览模式 d 保持下载含义，确认后复用原序号下载入口 |
| `downloader/models.py:Comic` | 已有名称、作者、来源、元数据、分组、章节和解析提示 | 详情面板可使用现有模型，不增加网络接口或任务格式 |
| `DriverManager` / `browser/drivers.py` | 缓存浏览器对象；CloakBrowser 包装同步 Playwright API | 不能把既有驱动随意迁移到不同线程，也不能并发共享一个驱动 |
| `PageLoader.load` | 同步 HTTP 请求，单次请求设置 30 秒超时，外层还有重试 | 取消 UI 等待不等于立即取消网络请求；总等待不能声称一定小于 30 秒 |
| `pyproject.toml` / 本地环境 | 已声明且已安装 prompt_toolkit 3.0.52 | 不需要引入新的终端 UI 框架依赖 |

本地依赖源码确认：`Application(full_screen=True)` 使用替代屏幕缓冲区；`HSplit`、`VSplit`、
`DynamicContainer` 可组成自适应布局；按键绑定支持焦点范围；`invalidate()` 提供线程安全的
重绘通知。Windows 有专用输入输出实现。这些证据说明接口具备所需能力，不代替实际终端验收。

## 使用流程

1. 用户输入 `s 猎人`，搜索按现有流程执行并保留逐源结果报告。
2. 交互式终端中有结果时进入搜索浏览模式，默认高亮第一项。原先屏幕输出在退出后恢复。
3. `↑/↓` 移动高亮，列表滚动跟随选择；跨出可视区域时自动滚动，无需输入页码。
4. 按 `Enter`，在详情区加载选中漫画；首次显示加载状态，成功后显示详情。
5. `Tab` 切换结果区和详情区焦点；在详情区使用方向键或 PageUp/PageDown 阅读长目录。
6. 按 `d` 打开当前高亮漫画的整本下载确认框；确认后暂停浏览界面并执行现有下载流程。
   下载完成或普通失败后返回浏览界面，保留高亮、筛选和滚动位置；取消确认则留在原处。
7. `Esc` 或 `q` 退出浏览，回到原命令行。可输入 `browse` 重新浏览最近搜索结果，保留本轮
   选择和本地筛选；下一次搜索替换结果集并重置浏览状态。

非交互子命令 `comic_downloader search ...`、管道和重定向输出保持文本形式。不支持终端控制的
环境使用原命令交互，并提示 `i <序号>`；可提供 `--plain` 显式选择文本交互，方便兼容和排障。
判断条件包括 stdin/stdout 的终端能力和 `TERM=dumb`，不能只根据 Windows/Linux 平台决定。

```text
│ [正篇]                                           │
│  1 第一话                                        │
│  2 第二话                                        │
│ ……                                               │
├──────────────────────────────────────────────────┤
│ ↑↓ 选择  Enter 详情  d 下载  Tab 切区  Esc 返回    │
└──────────────────────────────────────────────────┘
```

极小窗口（初始建议小于 48 列或 18 行）不强行塞入两块不可读的面板：显示尺寸提示，允许
放大窗口；提供单面板切换作为降级。正常尺寸的主体验始终是同屏分栏。缩放窗口不能丢失高亮项、
查找条件或已经获取的详情。

高亮行使用背景色，同时保留 `>` 标记；单色终端仍能识别。焦点区标题要有明显标识。
长名称截断或折行策略必须统一，完整名称在详情标题显示；布局长度按终端字符宽度计算。

## 按键与模式边界

| 按键 | 结果区 | 详情区 / 输入状态 |
| --- | --- | --- |
| `↑ / ↓` | 上下选择，不循环越界 | 详情区滚动；筛选输入中按输入控件规则处理 |
| `PageUp / PageDown` | 按当前可视高度翻动 | 详情区按屏滚动 |
| `Home / End` | 第一项 / 最后一项 | 详情开头 / 结尾 |
| `Enter` | 加载选中漫画详情 | 详情区针对当前选中漫画；筛选输入中应用筛选，确认框中激活当前按钮 |
| `d` | 打开选中漫画的整本下载确认框 | 详情区同样针对当前高亮漫画；筛选输入中的 d 只输入字符；确认框中不重复触发 |
| `Tab / Shift+Tab` | 切换区域焦点 | 同左；按键提示随焦点变化 |
| `/` | 打开本地筛选输入 | Enter 应用、Esc 取消编辑；过滤已缓存结果，不发请求 |
| `r` | 强制刷新当前漫画详情 | 同左；进行中的同一请求不重复提交 |
| `Esc / q` | 返回命令行 | 筛选编辑时 Esc 先关闭编辑；`q` 是可输入的查询字符 |
| `Ctrl+C` | 退出浏览并请求停止未开始的加载 | 恢复终端状态，不吞掉进程退出逻辑 |

关键约束：**Enter 查看详情，d 始终表示下载**。浏览模式的 d 针对高亮漫画，确认后相当于
命令行的 `d <漫画原序号>`，不是不带参数的 `d`，不能误用上一次预览或 Shell 当前漫画。
不能把未处理的按键残留传回命令行执行。界面底部持续说明快捷键；仅在浏览模式增加下载确认，
原命令行及直接 CLI 的参数、交互和退出码语义保持不变。

## 整本下载确认与执行

按 d 时立即冻结一个下载候选：搜索批次、原始序号、源代码、URL 和名称。确认框显示明确的
目标和下载范围，不要求先按 Enter 获取详情；缺少来源或 URL 的结果不能进入可确认状态。

```text
┌ 下载整本漫画？ ─────────────────────────────────┐
│ 漫画：全职猎人                                 │
│ 来源：读漫屋（dumanwu）                        │
│ 原序号：12                                     │
│ 保存到：D:\Comics                              │
│ 范围：所有分组中的全部可解析章节                │
│ 文件策略：校验并复用已有文件                    │
│                                                │
│            [取消]    [确认下载]                │
└────────────────────────────────────────────────┘
```

- 确认框为模态，背景高亮和筛选不能变化；焦点限制在确认框内。默认焦点在“取消”，Tab 或左右键
  切换按钮，Enter 激活当前按钮，Esc 取消。连续按 d 不叠加弹窗，不直接确认下载。
- 取消不创建下载计划、不启动下载所需的请求或浏览器、不切换当前漫画。此前已发出的独立详情
  预览请求可继续按生命周期规则处理，但其返回不能改变确认框中冻结的目标。
- 显示实际输出路径和当前覆盖策略。已有详情可显示分组/章节数并标注“预览”；未加载时显示
  “确认后获取目录”。不为弹出确认框隐式加载目录。已有解析提示需展示；整本范围是所选来源
  返回的全部可解析章节，不保证网站全书完整。
- 确认只提交一次结构化下载动作。执行前重新检查搜索批次及原序号对应的源和 URL；如果结果
  已变更，取消此次动作并提示重新选择，不能凭旧序号下载另一部漫画。
- Shell 控制层接收动作后，暂停全屏视图，停止接收新的预览任务并协调已有加载资源，调用
  `do_d(str(original_index + 1))`。不在确认框回调或预览线程里直接运行同步下载。
- 原入口会按源重新获取目录，再把所有分组的章节写入下载计划，因此范围与 `d 12` 一致，
  不受结果筛选、详情滚动位置或预览缓存影响。保留既有重试、文件复用、覆盖策略和任务记录。
- 下载期间使用现有 Rich 进度和日志输出，不让它与全屏界面同时绘制，也不接受重复下载按键。
  成功或普通失败后恢复浏览状态，并显示结果和任务 ID（若已创建）；需提供查看完整下载摘要
  的入口。Ctrl+C 沿用既有中断及任务恢复语义，恢复终端后返回原退出路径，不自动重试或重开弹窗。

仅查看详情仍不改变 Shell 当前漫画或来源；确认下载后，当前漫画及来源随原下载命令切换。
范围下载继续由 `i <序号>` 后的 `v` 命令承担，不在本轮增加章节多选下载。

## 详情状态与异步加载

每项详情有 `未加载 → 加载中 → 已加载 / 失败` 状态。状态和缓存按“源代码 + URL”关联，
不能只按名称关联，避免跨源同名漫画混淆。

- 只移动高亮不发起网络请求；可先展示搜索结果已有的名称、作者和来源。
- 已加载的项重新选中时直接显示本次会话缓存；`r` 才强制刷新。
- 从 A 移到 B 时，详情面板立即切到 B 的缓存或“按 Enter 加载”提示，不继续把 A 的内容伪装成 B。
- 每次选择/请求携带递增 generation。后台完成后，仅把与当前选择及 generation 一致的结果
  应用到当前面板。旧结果可在有效会话中缓存，但不能覆盖当前画面。
- 连续按 Enter 不重复请求。采用“最多一个运行请求 + 一个最新待执行请求”的队列；新的选择替换
  旧待执行项，不为快速移动创建无限线程或请求。
- 请求失败、验证码、浏览器初始化失败显示在详情区，可按 r 重试；搜索列表保持可用。
- 详情包括名称、来源、作者、其他元数据、分组/章节数量、章节目录和既有解析提示。
  空目录、解析不完整和请求失败分别呈现，不能只显示空白区域。

详情加载使用专用工作线程，**在同一线程内创建、使用和销毁自己的 HTTP Session、源实例与
浏览器驱动**，不直接共享 Shell 当前驱动。HTTP 遇到 403/429 回退到浏览器时，也必须遵守此
归属约束。UI 线程只维护模型和渲染，通过事件队列接收结果。现有 Rich 状态动画及源日志不能
与 prompt_toolkit 同时争用同一屏幕，需要加载器将反馈转换为事件，调试日志写文件。

退出时停止提交新任务、丢弃待执行项，并在拥有资源的线程清理。同步网络/浏览器调用不保证能
立即强制终止；不把 `Future.cancel()` 当作正在执行的请求已取消。开发阶段必须明确“返回浏览
前页面”和“应用进程完全退出”的等待行为，避免重复创建后台 worker 或遗留浏览器进程。
若这一实现不能通过退出清理验收，应先解决工作进程隔离或可取消加载边界，不默认启用新 UI。

## 技术方案选择

| 方案 | 优点 | 成本与问题 | 结论 |
| --- | --- | --- | --- |
| Rich Live/Layout + 自写按键输入 | 能延用部分现有展示 | 需要自行处理 Windows 按键、焦点、输入法、缩放及线程间输出 | 不选为主方案 |
| 已有 prompt_toolkit Application | 已安装；具备按键、焦点、输入、分栏及 Windows 后端 | 需新增浏览状态和无直接输出的详情服务 | 推荐 |
| 引入完整新 TUI 框架 | 方便进一步发展多页面界面 | 新增依赖，扩大迁移和打包范围；当前需求不要求全应用迁移 | 暂不引入 |

建议代码边界（名称可在实施时调整）：

- `downloader/search_browser/state.py`：原索引、高亮、筛选、焦点、详情状态、请求 generation、冻结的下载候选。
- `downloader/search_browser/view.py`：prompt_toolkit 布局、样式、按键、下载确认框和终端尺寸处理。
- `downloader/search_browser/loader.py`：按源绑定加载详情，拥有独立资源，反馈数据和事件。
- `Shell.do_s` / `do_browse`：搜索结果快照、进入条件、退出状态、下载动作交接及浏览状态恢复；直接 CLI 不进入全屏。
- `Shell.do_d`：复用现有原序号下载入口，不新增第二套下载执行逻辑。
- `main.py`：显式文本模式选项；退出清理与错误边界。

首版覆盖“搜索结果选择 + 同屏详情 + 确认整本下载”，保留现有任务、归档和下载命令。完整应用全屏化、
搜索时实时插入结果、后台下载队列、封面图片和鼠标操作均为后续独立设计项。

## 隔离原型结果与证据边界

2026-10-27 在本机 Python 3.14.2、prompt_toolkit 3.0.52 下，使用 Windows 管道输入、
Application 真实事件循环和 DummyOutput 的内存屏幕执行了原型，结果 PASS：

- 方向键选择与实际屏幕单元格的高亮 style；
- 初版使用 d 加载当前高亮项；模拟 I/O 等待期间仍能移动并发起新选择；按键方案现已改为 Enter，
  确认框与下载交接需要按修订后的规则单独验证，不能直接沿用初版原型的结论；
- 故意使旧请求较晚返回，确认不覆盖新项详情；
- Tab 切换焦点；120 列左右布局、80/40 列上下布局；
- 运行中调整尺寸后保留选择；q 正常退出事件循环。

原型位于本地忽略目录 `.agent-test-temp/browser_feasibility.py`，不进入生产代码或提交。
它只用合成数据和 asyncio 延迟模拟加载；没有发起 HTTP、启动浏览器或执行下载。
内存屏幕证明布局和事件机制可工作，**不能证明真实终端无闪烁、中文字体完美显示，或真实
浏览器可以跨线程共享**；本方案也不依赖后一假设。

## 开发阶段与验收门槛

1. **浏览组件与状态**：用固定数据实现选择、分栏、滚动、焦点、本地筛选与下载确认框；覆盖空结果、单条、
   上千条、中文长标题、窗口缩放。每帧只生成可视区域所需内容，避免全部章节反复排版。
2. **详情服务接入**：从同步命令中提取加载边界，覆盖 HTTP、需要浏览器的源和 HTTP 回退；
   测试资源创建/使用/关闭的线程一致，超时、旧结果、快速按键、取消及异常退出。
3. **下载交接与 Shell 集成**：增加 browse、终端检测及文本降级，确认后按原序号调用 d；
   验证一次确认只产生一次执行，取消无副作用，下载后恢复浏览状态，Ctrl+C 正确清理。
4. **默认开启**：确认原 d/i/v 和直接 CLI 不变；通过真实 Windows Terminal/PowerShell 的
   人工验证和打包 smoke test 后再默认开启。

- `s` 后可直接 ↑↓ 选择，按 Enter 同屏显示正确漫画的详情，不执行下载。
- d 只弹出确认框；默认取消、Esc 取消和连续按 d 均不下载，确认后才调用一次原序号下载入口。
- 未预览详情也能确认整本下载；所有分组都包含在计划内，筛选后的原序号和来源对应正确。
- 弹窗中背景选择不能变化；详情晚返回不改变下载目标；搜索结果变更后拒绝陈旧下载动作。
- 下载成功或普通失败后恢复高亮、筛选及滚动位置；Ctrl+C 沿用现有中断语义并正确恢复终端。
- 列表和详情可以各自滚动；宽窄布局均能完成相同操作，尺寸改变不重置上下文。
- 请求等待时输入仍可响应，失败可重试；A→B 快速切换不会展示错配详情。
- 筛选不改变原始序号；输入关键词时 d/q 不触发动作。
- 退出/异常后终端回显、光标和输入模式恢复；不遗留未管理的加载线程或浏览器进程。
- 直接 CLI、重定向、文本模式保持原有输出及退出码语义。
- 全量现有回归通过；新增状态、按键、确认框、渲染、加载器和 Shell 下载集成测试通过。
