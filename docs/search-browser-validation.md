# 键盘搜索浏览：实施与验证记录

2026-10-27，根据已确认的[交互设计](ideation/2026-10-27-keyboard-search-browser.md)完成实现。

## 实现范围

- 搜索结束自动进入浏览；`browse` 可重新打开。`↑↓` 高亮，`Enter` 同屏详情，`d` 确认整本下载。
- 宽屏左右、普通窄屏上下、小窗口单面板；列表按可见行渲染，长详情和长确认文本按实际宽度换行滚动。
- 下载确认默认取消，确认对象冻结为原序号、来源、URL 和搜索代次。执行前再次校验身份，复用 `Shell.do_d`。
- 正常下载完成或普通失败后保留浏览位置，`l` 可查看下载摘要与任务 ID；Ctrl+C 沿用原中断处理。
- 详情最多缓存 20 本；单工作线程最多处理一个当前请求和一个可替换的待处理请求，过期响应不覆盖其他漫画。
- 预览 HTTP 会话、源对象、配置浏览器和 HTTP 403/429 的临时回退浏览器均在工作线程内创建、使用和清理。
- `--plain`、非交互输出、`TERM=dumb` 及终端初始化失败时使用文本交互。

## 已知行为边界

退出或确认下载时，会取消排队中的详情请求，并等待当前同步调用结束后清理预览资源。
同步请求、浏览器初始化和页面加载无法强制即时中断；等待可能跨越超时及重试，界面持续显示等待提示。
窗口不足 48 列或 18 行时禁止打开下载确认，用户可以放大窗口或回到文本命令下载。

预览详情与文本命令的当前漫画独立。连续多话范围下载需返回命令行执行 `i <原序号>`，再使用 `v`。
整本下载重新获取目录，任务完成仍仅表示全部已解析并选入计划的章节处理完成。

## 2026-10-28：详情区卷 / 单话选择与确认下载

详情区增加逐行高亮，按 `Tab` 切入后使用上下键移动，卷名或具体话上按 `v` 打开确认框。
卷名对应 `v <卷序号>`，单话对应 `v <卷序号> <话序号> <话序号>`，确认框默认取消。
文字换行仍对应同一目录条目，窗口改变宽度后保留所选逻辑行。

确认对象保存原漫画身份、卷序号、话序号及所选章节的名称和 URL。执行时先用原搜索序号获取
当前目录，再检查选中卷或话的身份和位置，校验通过后调用现有 `Shell.do_v`。所选卷内容、
单话位置或地址发生变化时，不创建下载任务，提示刷新；其他漫画或无关章节不参与下载。
加载中、错误页、简介、空白行、空卷和下载摘要不会发起章节下载。

## 2026-10-28：命令前缀提示与 Tab 补全

命令行输入使用已有 prompt_toolkit 提供候选列表；候选来自实际 `do_*` 命令及其帮助说明，
不显示内部 EOF 命令。输入 `b` 显示 `browse`；Tab 正向循环、Shift+Tab 反向循环，
Esc 恢复补全前的输入，回车执行。空输入按 Tab 显示全部命令，参数、URL 和搜索词不参与命令补全。
Tab 对本地候选同步选择，保证快速连续输入 `b`、Tab、Enter 时提交完整命令。

`--plain`、管道和 `TERM=dumb` 保留原文本输入；终端初始化或提示输入失败时退回文本模式。
同一个补全会话可连续接受命令，切换源后显示更新的提示符；命令队列、空行、EOF 及 Ctrl+C
继续沿用原命令执行语义。
