# 键盘搜索浏览：实施与验证记录

2026-10-27，根据已确认的[交互设计](ideation/2026-10-27-keyboard-search-browser.md)完成实现。

## 实现范围

- 搜索结束自动进入浏览；`browse` 可重新打开。`↑↓` 高亮，`Enter` 同屏详情，`d` 确认整本下载。
- 宽屏左右、普通窄屏上下、小窗口单面板；列表按可见行渲染，长详情和长确认文本按实际宽度换行滚动。
- 下载确认默认取消，确认对象冻结为原序号、来源、URL 和搜索代次。执行前再次校验身份，复用 `Shell.do_d`。
- 正常下载完成或普通失败后保留浏览位置，`l` 可查看下载摘要与任务 ID；Ctrl+C 沿用原中断处理。
- 详情最多缓存 20 本；单工作线程最多处理一个当前请求和一个可替换的待处理请求，过期响应不覆盖其他漫画。
- 预览 HTTP 会话、源对象、配置浏览器和 HTTP 403/429 的临时回退浏览器均在工作线程内创建、使用和清理。
- `--plain`、非交互输出、`TERM=dumb` 及终端初始化失败时使用文本交互。

## 已知行为边界

退出或确认下载时，会取消排队中的详情请求，并等待当前同步调用结束后清理预览资源。
同步请求、浏览器初始化和页面加载无法强制即时中断；等待可能跨越超时及重试，界面持续显示等待提示。
窗口不足 48 列或 18 行时禁止打开下载确认，用户可以放大窗口或回到文本命令下载。

预览详情与文本命令的当前漫画独立。范围下载需返回命令行执行 `i <原序号>`，再使用 `v`。
整本下载重新获取目录，任务完成仍仅表示全部已解析并选入计划的章节处理完成。
